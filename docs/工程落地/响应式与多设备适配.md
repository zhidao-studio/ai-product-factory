# 响应式与多设备适配

> 模块：工程落地 ｜ 关联：栅格与布局、平台适配、无障碍设计
> 覆盖：断点、折叠屏、平板、横屏、安全区、折叠屏铰链避让。

---

## 1. 断点系统（与设计 Token 对齐）

| 断点 | px | 典型设备 |
|---|---|---|
| xs | <480 | 小手机竖屏 |
| sm | 480~575 | 大手机 |
| md | 576~767 | 平板竖屏 / 手机横屏 |
| lg | 768~991 | 平板横屏 / 小笔记本 |
| xl | 992~1199 | 笔记本 |
| xxl | 1200~1599 | 台式 |
| xxxl | ≥1920 | 大屏 |

- 移动优先：先写 xs，再用 `min-width` 媒体查询向上增强（不要 desktop-first 然后隐藏）。
- 栅格：PC 用 24 列（`Row`/`Col`）；移动端用 `Col span` 或 fl␣ `flex` 单列流。

---

## 2. 折叠屏（Foldable）

- **展开/折叠切换**：监听 `screen` 变化，布局需实时重排（不依赖一次性加载）。
- **铰链避让**：双屏中间铰链区（约 40~80px）不放置关键内容/按钮，用安全 padding。
- **断点特殊值**：展开态宽度常落在 lg~xl，按 `md`/`lg` 重排为双列/分栏。
- 测试：必须在折叠态 + 展开态各验一遍交互。

---

## 3. 平板（Tablet）

- 介于手机与 PC：导航可用**左侧收窄抽屉**或底部 Tab。
- 列表→详情：平板可用**主从分栏**（左列表 40% / 右详情 60%），非全屏跳转。
- 触控目标：平板按移动端 ≥ 44px（触屏模式），接键盘时按 PC 32px。

---

## 4. 横屏（Landscape）

- 手机横屏：避免内容过宽，限制最大宽度（如 680px 居中）。
- 游戏/视频类横屏：全屏沉浸，隐藏状态栏。
- 输入密集页横屏：键盘遮挡，需滚动定位到当前输入。

---

## 5. 安全区（Safe Area）

- iOS：`env(safe-area-inset-top/right/bottom/left)`，顶部刘海、底部 Home Indicator。
- 小程序/H5：`padding-bottom: env(safe-area-inset-bottom)` 保底部 Tab 不被胶囊/手势条挡。
- 全屏页：内容内缩安全区，不贴边。

```css
.tab-bar { padding-bottom: calc(8px + env(safe-area-inset-bottom)); }
```

---

## 6. 视口与缩放

- H5 必须：`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`。
- `viewport-fit=cover` 才能用 `env(safe-area-inset-*)`。
- 禁止 `user-scalable=no`（阻碍无障碍缩放）。

---

## 7. 反模式

- ❌ desktop-first 靠隐藏做移动端
- ❌ 折叠屏仅测一种形态
- ❌ 铰链区放关键按钮
- ❌ 忘记 `viewport-fit=cover` 导致安全区失效
- ❌ 禁用用户缩放
