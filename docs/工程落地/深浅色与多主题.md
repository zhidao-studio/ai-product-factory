# 深浅色与多主题

> 模块：工程落地 ｜ 关联：Design Token 架构、主题切换实现、色彩系统
> 核心：**主题切换是 Token 的派生，不是重写样式**。一切靠 `algorithm` + Seed 派生，禁止双套手写 CSS。

---

## 1. 三种主题模式

| 模式 | antd 实现 | 用途 |
|---|---|---|
| 浅色 Light | `theme.defaultAlgorithm` | 默认 |
| 深色 Dark | `theme.darkAlgorithm` | 夜间 / 大屏 / 护眼 |
| 紧凑 Compact | `theme.compactAlgorithm` | 信息密度高的后台 |

- **组合**：`algorithm: [theme.darkAlgorithm, theme.compactAlgorithm]` 可叠加。
- **品牌主题**：改 `colorPrimary` 等 Seed，其余全链路自动派生（见 Design Token 架构）。

---

## 2. 切换实现（无闪烁）

PC / H5：
```tsx
import { ConfigProvider, theme, App as AntdApp } from 'antd';

const [mode, setMode] = useState<'light'|'dark'>(
  () => localStorage.getItem('theme') as any || 'light'
);

useEffect(() => {
  document.documentElement.dataset.theme = mode;       // CSS 变量同步
  localStorage.setItem('theme', mode);
}, [mode]);

const algorithm = mode === 'dark' ? theme.darkAlgorithm : theme.defaultAlgorithm;

<ConfigProvider theme={{ token: tokens, algorithm, cssVar: true }}>
  <AntdApp>{children}</AntdApp>
</ConfigProvider>
```

- **跟随系统**：`window.matchMedia('(prefers-color-scheme: dark)')` 初始化，并监听变化（用户未手动选过时）。
- **无闪烁**：在 `<head>` 内联一段同步脚本读取 localStorage 设 `data-theme`，避免首屏白闪。

---

## 3. 过渡动画（防刺眼）

- 主题切换加全局过渡：`* { transition: background-color .2s, border-color .2s, color .2s; }`
- 仅在 `theme-change` 期间启用，切完移除，避免日常交互卡顿（用一次性 class 控制）。
- 禁止对 `box-shadow`/`transform` 加过渡（导致动画异常）。

---

## 4. 自定义组件适配

- 任何自定义组件**必须消费 CSS 变量**（`var(--color-bg-container)` 等），不写死色。
- 开启 `cssVar: true` 后，antd 会把 Token 注入 `:root` 的 `--ant-*` / 自定义 `--color-*` 变量。
- 非 antd 区域（图表/ECharts）读同一套色板（见 数据可视化/图表色彩与色板 的 light/dark）。

```css
.my-card { background: var(--color-bg-container); color: var(--color-text); }
```

---

## 5. 多品牌主题（可选）

- 同一产品多租户换肤：只换 Seed（`colorPrimary` + 少量语义），不碰 Map/Alias。
- 提供 `presets`：`{ brandA: {...seed}, brandB: {...seed} }`，运行时切换。
- 禁止为不同品牌维护两套完整 CSS。

---

## 6. 反模式

- ❌ 深色模式手填一套色（应用 darkAlgorithm）
- ❌ 自定义组件写死色值（不读 CSS 变量）
- ❌ 切换无过渡导致刺眼
- ❌ 首屏白闪（缺内联同步脚本）
- ❌ 多品牌两套完整样式
