# 无障碍验收表

> WCAG 2.1 AA 专项验收。强制项不通过禁止发布。

---

## 1. 对比度（强制）

- [ ] 正文文本对比度 ≥ 4.5:1
- [ ] 大文本（18px+ / 14px+bold）≥ 3:1
- [ ] UI 组件（边框/图标）≥ 3:1
- [ ] 深色模式对比度重新校验

## 2. 键盘可达（强制）

- [ ] 所有交互元素可 Tab 到达
- [ ] 焦点顺序 = 视觉阅读顺序
- [ ] 可见焦点轮廓（不被 outline:none 移除）
- [ ] 弹窗打开焦点移入，关闭返回触发元素
- [ ] Esc 关闭 Modal/Drawer；Enter/Space 触发

## 3. 语义与读屏（强制）

- [ ] 语义标签（nav/main/aside/section）
- [ ] 图片 `alt`；装饰图 `alt=""`
- [ ] 表单 `<label>` 关联；错误 `aria-describedby`
- [ ] 图标按钮 `aria-label`
- [ ] 动态内容 `aria-live`（Toast/计数）

## 4. 色盲友好（强制）

- [ ] 状态不止靠颜色（配图标/文字）
- [ ] 图表非纯色相区分（图案/标签）
- [ ] 错误 = 错误色 + ⚠ + 文案

## 5. 触控目标（强制·移动端）

- [ ] 最小触控区 44×44pt（iOS）/ 48×48（Android/HarmonyOS）
- [ ] 图标按钮热区补足

## 6. 动态字号（推荐）

- [ ] 支持系统字号放大不破版
- [ ] 极端字号下文字截断 + Tooltip，不挤压

## 7. 动效偏好（推荐）

- [ ] 尊重 `prefers-reduced-motion`
- [ ] 提供关闭动画入口
