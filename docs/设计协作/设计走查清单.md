# 设计走查清单

> 上线前设计/开发联合走查，逐项验收。未通过不得发布。

---

## 1. 视觉一致性

- [ ] 所有颜色来自 Token（无硬编码色值）
- [ ] 所有间距来自 8px 梯度（无 3/5/7px 等）
- [ ] 圆角来自梯度（6/8/4/2）
- [ ] 字号来自梯度（14 基准，种类 ≤ 5）
- [ ] 字体族为系统默认
- [ ] 阴影来自三层梯度
- [ ] 组件样式与 Figma 库 1:1 一致

## 2. 组件规范

- [ ] 主操作唯一（每屏 ≤ 1 个 primary）
- [ ] 按钮状态完整（default/hover/active/disabled/loading）
- [ ] 输入框焦点态主色 + outline
- [ ] 错误态有文案说明
- [ ] 加载必有动画（非卡死感）
- [ ] 空态有插图 + 文案 + 引导

## 3. 布局与响应式

- [ ] PC 用 24 列栅格，断点生效
- [ ] 移动端安全区适配（刘海/Home）
- [ ] 无横向滚动（小屏）
- [ ] 内容宽度随断点缩放

## 4. 交互与反馈

- [ ] 操作 100ms 内反馈
- [ ] 模态框有遮罩 + 阴影
- [ ] 危险操作二次确认
- [ ] 提交 loading + 成功/失败提示
- [ ] 动效时长/曲线来自库

## 5. 深色模式

- [ ] 切深色无对比度问题
- [ ] 图片/插图深色适配
- [ ] 阴影/边框深色正确

## 6. 跨端

- [ ] iOS/Android/HarmonyOS 遵循各自原生惯例
- [ ] 小程序菜单胶囊区域已预留
- [ ] 小程序 rpx 适配多机型

---

## 使用方式

- 开发自测 → 设计复审 → 走查清单全勾 → 发布
- 遗留项登记 Issue，标注严重级别
