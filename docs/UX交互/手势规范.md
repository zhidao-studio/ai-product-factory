# 手势规范

> 模块：UX 交互 ｜ 适用：移动端（iOS / Android / HarmonyOS）/ H5 / 小程序
> 关联：反馈机制、平台适配各端
> 核心：手势是移动端的"鼠标"，必须**可发现、可撤销、有反馈**。

---

## 1. 通用手势清单

| 手势 | 含义 | 反馈 |
|---|---|---|
| 点按 Tap | 选择/打开 | 100ms 内高亮/缩放反馈（Ripple / 透明度） |
| 长按 Long-press | 弹出菜单/多选 | 500ms 触发，震动（Android/Harmony） |
| 左滑 Swipe-left | 删除/更多操作 | 露出操作按钮，二次确认删除 |
| 右滑 Swipe-right | 返回（iOS 强预期） | 跟随手指的转场 |
| 下拉 Pull-down | 刷新 | 加载指示器 + 回弹 |
| 上拉 Pull-up | 加载更多 | 底部 spinner |
| 双指捏合 Pinch | 缩放（图片/地图） | 平滑缩放 |
| 横扫 Swipe（轮播） | 翻页 | 页面吸附 |

---

## 2. 平台差异（必须遵守）

| 行为 | iOS | Android | HarmonyOS |
|---|---|---|---|
| 返回 | 左滑 + 左上返回键 | 物理/手势返回 | 左滑 + 系统导航条 |
| 删除（列表） | 左滑露出"删除" | 长按或左滑 | 左滑 |
| 刷新 | 下拉（含弹性回弹） | 下拉（Material 圆环） | 下拉 |
| 长按菜单 | 3D Touch 已弃，用长按 | 长按 + Ripple | 长按 + 震动 |

---

## 3. 设计约束

- **可发现**：非常规手势（如长按）首次使用时给 hint（"长按可拖拽"）。
- **可撤销**：删除/归档等破坏性手势操作后，提供 Undo（Snackbar 内"撤销"）。
- **反馈一致**：同一手势全局含义一致，不要 A 页左滑删、B 页左滑归档。
- **触控热区**：手势响应区 ≥ 44px（iOS）/ 48px（Android/Harmony），小元素需放大热区。
- **冲突避免**：可滚动容器内慎用横向滑动手势，避免与滚动抢事件。

## 4. 跨端代码（React）

```tsx
// 列表项左滑删除（antd-mobile SwipeAction / RN react-native-gesture-handler）
<SwipeAction right={[{ text:'删除', color:'var(--adm-color-danger)', onClick: del }]}>
  <List.Item>{row}</List.Item>
</SwipeAction>

// 下拉刷新（antd-mobile PullToRefresh）
<PullToRefresh onRefresh={refresh}>{list}</PullToRefresh>
```

---

## 5. 反模式

- ❌ 破坏性手势无撤销
- ❌ 同一手势跨页语义不一致
- ❌ 热区 < 44px 且未放大
- ❌ iOS 强行用 Android 物理返回心智
- ❌ 非常规手势无任何提示

---

## 6. 自检

- [ ] 手势语义全局一致
- [ ] 破坏性手势有 Undo
- [ ] 热区 ≥ 平台最小值
- [ ] 平台返回/刷新符合官方预期
- [ ] 非常规手势有提示
