# 导航模式

> 导航确保用户「知所在、明去向、可返回」。分平台与分场景定义。

---

## 1. PC Web 导航

| 模式 | 场景 | 组件 |
|---|---|---|
| 顶部导航 | 一级 ≤ 5 | `Menu` horizontal |
| 侧边导航 | 多级中后台 | `Menu` inline / `Layout.Sider` |
| 混合 | 复杂系统 | 顶部+侧边 |
| 面包屑 | 层级指示 | `Breadcrumb` |
| 标签 | 页内切换 | `Tabs` |

---

## 2. 移动端导航

| 模式 | 场景 | 平台 |
|---|---|---|
| 底部 Tab | 2~5 主页面 | 全平台 |
| 顶部 Tab | 页内切换 | 全平台 |
| 抽屉 | > 5 入口 | 全平台 |
| 返回按钮 | 次级页左上 | 全平台 |
| 侧滑返回 | iOS 返回 | iOS |

---

## 3. 底部标签栏规范

| 参数 | 值 |
|---|---|
| 标签数 | 2~5（推荐 3~4） |
| 栏高 | 49px(iOS)/56dp(Android)/56vp |
| 图标 | 24×24 |
| 文字 | 10~12px |
| 选中 | 图标填充 + 文字主色 |
| 未选 | 图标描边 + 灰色 |

---

## 4. 微信小程序导航

- 右上角胶囊不可自定义，预留空间
- 首页可用原生底部 Tab（2~5）
- 次级页左上返回；iOS 右滑 / Android 物理键

---

## 5. 导航原则

- 当前页高亮（[Menu](../../组件库/导航/Menu.md) 选中态）
- 层级 ≤ 3（深则用搜索/面包屑）
- 返回路径明确，无死页
- 移动端避免 PC 侧边 Menu 直接移植

---

## 6. 规则

- ✅ 每页有且唯一当前位置指示
- ✅ Tab ≤ 5
- ❌ 导航项文案含糊
- ❌ 移动端用面包屑（用返回按钮）
