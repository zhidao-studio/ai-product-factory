# 依赖安全基线

## 自动治理

- Dependabot 每周分别检查 Maven、4 个独立前端和 3 个容器工程。
- Pull Request 的 Dependency Review 会阻止新增 high/critical 级依赖风险。
- 依赖升级必须通过该工程的独立 CI，不以共享锁文件联动升级。

## React Native 已知例外

`npm audit --omit=dev` 会通过 React Native/Metro 构建链报告 `image-size`、`braces` 和 `fast-xml-parser` 的中高级问题。当前上游给出的自动修复需要降级 React Native 或 Ant Design RN，属于不可接受的破坏性变更。

当前处置：

- 这些包用于 Metro/原生工程解析、codemod 或 CLI，不会打入用户设备的 JS 业务 Bundle。
- CI 只处理仓库内受信任资源，不向这些工具传入用户上传的 XML/图像/glob。
- 不执行 `npm audit fix --force`；由 Dependabot 跟踪 React Native、Metro、CLI 和 Ant Design RN 的上游修复。
- 例外复审日期：2026-09-30；如上游提供兼容修复，应立即升级并删除本例外。
