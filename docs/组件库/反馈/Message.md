# Message 轻提示

> 轻提示（Toast）反馈操作结果，不打断流程，自动消失。

---

## 1. 概述

用于轻量级结果反馈：成功保存、网络异常。错误提示若需明确告知，用 Modal 或行内。

---

## 2. 解剖结构

```
        ┌─────────────────────┐
        │ [✓] 操作成功          │ ← 图标 + 文字，居中浮于顶部
        └─────────────────────┘
              （2~3s 自动消失）
```

---

## 3. 变体

| 类型 | 图标 | 时长 | 用途 |
|---|---|---|---|
| success | ✓ | 3s | 成功提示 |
| error | ✕ | 3s（或常驻需手动关） | 错误提示 |
| warning | ⚠ | 3s | 警告 |
| info | ℹ | 3s | 信息 |
| loading | spinner | 持续 | 进行中 |

---

## 4. 位置与行为

- PC：顶部居中，叠放不重叠
- 移动端：`Toast` 居中或底部，1.5s 消失
- 同页同时至多 1 个加载动画（见 [微信小程序设计指南](../../平台适配/微信小程序.md)）

---

## 5. Do / Don't

**Do**
- ✅ 成功类用 1.5~3s 自动消失
- ✅ 文案简洁（"已保存"）
- ✅ 加载用 loading 类型

**Don't**
- ❌ 用成功 Toast 表错误（错误需明确）
- ❌ 长文案堆 Toast（用 Modal/Alert）
- ❌ 关键错误一闪而过（用 Modal 或常驻 error）

---

## 6. 代码

```tsx
// PC
message.success('已保存');
message.error('保存失败，请重试');

// 移动端 (antd-mobile)
Toast.show({ icon: 'success', content: '已保存' });
```

---

## 7. 无障碍

- `role="alert"` + `aria-live="polite"`
- 读屏播报文字
