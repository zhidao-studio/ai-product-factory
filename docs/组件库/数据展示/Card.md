# Card 卡片

> 卡片是内容分组的容器单元。聚合相关标题、数据、操作。

---

## 1. 概述

用于信息聚合：数据面板、列表项、表单区块、图表容器。

---

## 2. 解剖结构

```
┌────────────────────────────┐
│ 标题            [更多>]      │ ← Header (标题+可选操作)
├────────────────────────────┤
│ 内容区（任意组件）           │ ← Body (内边距 24px)
│                            │
├────────────────────────────┤
│ 底部操作（可选）             │ ← Footer
└────────────────────────────┘
```

---

## 3. 变体

| 类型 | 说明 |
|---|---|
| 基础卡片 | 白底 + 1px 边框或轻阴影 |
| 无边框 | `bordered={false}`，靠间距分组 |
| 栅格卡片 | 列表式排列（如商品卡） |
| 可悬停 | hover 阴影增强（点击进入详情） |
| 加载卡 | Skeleton 占位 |

---

## 4. 尺寸

- 圆角：`borderRadiusLG` 8px
- 内边距：24px（默认）/ 16px（紧凑）
- 阴影：默认 `boxShadowTertiary` 或仅边框

---

## 5. 栅格排列

```tsx
<Row gutter={[16,16]}>
  <Col span={8}><Card>...</Card></Col>
  <Col span={8}><Card>...</Card></Col>
  <Col span={8}><Card>...</Card></Col>
</Row>
```

---

## 6. Do / Don't

**Do**
- ✅ 卡片内信息相关性强
- ✅ 同页卡片间距统一 16px
- ✅ 可点击卡片整体可点 + hover 反馈

**Don't**
- ❌ 一屏卡片过多无分组
- ❌ 卡片内再套复杂卡片（层级混乱）

---

## 7. 代码

```tsx
<Card title="销售概览" extra={<a>更多</a>} hoverable>
  <Statistic title="今日" value={1128} />
</Card>
```
