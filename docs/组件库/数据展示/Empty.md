# Empty 空状态

> 空状态在无数据时引导用户，是体验的「兜底」。

---

## 1. 概述

用于：列表无数据、搜索无结果、无权限、无网络。

---

## 2. 解剖结构

```
        ┌──────────┐
        │  插图     │ ← 简洁插画(48px+)
        ├──────────┤
        │ 暂无数据   │ ← 说明文字(14px, 二级色)
        │ [新建]     │ ← 引导操作(主按钮,可选)
        └──────────┘
```

---

## 3. 变体

| 类型 | 插图 | 文案 | 操作 |
|---|---|---|---|
| 无数据 | 空盒 | 暂无数据 | 创建按钮 |
| 无搜索结果 | 放大镜 | 未找到相关结果 | 修改筛选 |
| 无网络 | 断线 | 网络连接失败 | 重试 |
| 无权限 | 锁 | 暂无权限访问 | 申请权限 |

---

## 4. Do / Don't

**Do**
- ✅ 空态必有插图 + 文案 + 引导操作
- ✅ 文案说明原因（"暂无数据"而非"空"）
- ✅ 提供下一步入口

**Don't**
- ❌ 空白页面无说明（用户以为加载失败）
- ❌ 无操作引导（卡住）

---

## 5. 代码

```tsx
<Empty image={Empty.PRESENTED_IMAGE_SIMPLE} description="暂无数据">
  <Button type="primary">新建</Button>
</Empty>
```
