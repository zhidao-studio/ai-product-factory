# List 列表

> 列表是移动端与简单 PC 场景的最高频数据容器。表格的移动端替代（见 [Table](Table.md)）。

---

## 1. 概述

用于线性数据展示：消息、记录、设置项。移动端主列表优于表格。

---

## 2. 解剖结构

```
┌──────────────────────────────────┐
│ [◯头像] 标题文字       [操作>]     │ ← Item (左:图标/头像, 中:标题+描述, 右:操作)
│          描述文字（二级色）         │
├──────────────────────────────────┤
│ [◯头像] 标题文字       [操作>]     │
└──────────────────────────────────┘
        ↑ 分割线(左缩进16px)
```

---

## 3. 状态

- Default / Hover(PC) / Active(按下, 移动端) / Disabled
- 选中项主色文字或背景
- 滑动出现操作（SwipeAction，移动端）

---

## 4. 变体

| 类型 | 说明 |
|---|---|
| 基础列表 | 标题 + 描述 |
| 带图标/头像 | 左侧视觉元素 |
| 带操作 | 右侧箭头/按钮 |
| 可滑动 | 左滑显示删除/更多 |
| 加载更多 | 底部无限滚动 |
| 空 | `Empty` |

---

## 5. 尺寸

| 参数 | 值 |
|---|---|
| 最小行高 | 48px |
| 左右边距 | 16px |
| 分割线 | 左起 16px，右侧到边 |
| 图标 | 24px（头像 40px） |

---

## 6. Do / Don't

**Do**
- ✅ 移动端主列表用 List 而非 Table
- ✅ 行内操作右对齐，次要操作 SwipeAction
- ✅ 长列表触底自动加载

**Don't**
- ❌ 列表项高度不统一（视觉跳动）
- ❌ 一行塞过多操作（收进 SwipeAction）

---

## 7. 代码

```tsx
// 移动端 (antd-mobile)
<List>
  <List.Item prefix={<Avatar />} description="描述" onClick={...}
    extra={<Switch />}>标题</List.Item>
</List>

// PC
<List dataSource={data} renderItem={i => <List.Item>{i.title}</List.Item>} />
```
