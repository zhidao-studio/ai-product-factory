## 1.5 组件层级图例（通用 / 平台专有）

上表矩阵按"端"标了每个组件的实现；按下表判断**它到底通不通用**：

| 分类 | 含义 | 组件 |
|---|---|---|
| **通用组件** | 全端同一定义，仅尺寸/样式微调 | Button、Icon、Avatar、Tag、Badge、Input、Switch、Checkbox、Radio、Form、Card、List、Tabs、Empty、Result、Progress、Steps、Modal/Dialog（反馈语义）、Spin |
| **PC 专有** | 仅 PC Web 存在，移动端无对应、用别的替代 | Table（移动端→List）、Pagination、Breadcrumb、Menu（侧边导航）、Notification、Typography |
| **移动/小程序专有** | 该端特有交互范式 | NavBar、TabBar（移动·H5·小程序）；ImageUploader、Toast、Popup、Picker（移动端组件名） |
| **跨端同名异实现** | 概念通用，但各端组件不同 | Select(PC)=Picker(移动)、Upload(PC)=ImageUploader(移动)、Message=Toast、Drawer=Popup(position)、Dropdown=Popover、DatePicker 形态各异 |

**使用规则**：
- 写某端页面 → 查矩阵"该端列"的值；值为 `— (List)` 表示此端无该组件，用 `List` 替代（典型：移动端禁用 `Table`）。
- 通用组件直接套定义；平台专有组件只在其对应端的 `平台适配/<端>.md` 与组件库跨端说明里生效。

## 3. 状态标准（全组件通用）

| 状态 | 含义 | 视觉表达 |
|---|---|---|
| Default | 默认可交互 | 基础样式 |
| Hover | 鼠标悬浮 | 背景/边框变化（PC 专用） |
| Active / Pressed | 按下 | 主色加深（激活态色） |
| Focus / Selected | 聚焦/选中 | 主色描边 + `controlOutline` |
| Disabled | 禁用 | 灰色 + 降低不透明度 |
| Loading | 加载中 | Spinner + 禁用交互 |
| Error | 错误 | 错误色边框 + 错误文案 |

## 4. 变体维度（通用）

- **Type**：primary / default / dashed / text / link
- **Size**：large / middle / small
- **Status**：normal / error / warning / success
- **Shape**：default / round / circle

## 5. 组件优先级（本系统详细撰写）

| 优先级 | 组件 | 说明 |
|---|---|---|
| P0 | Button / Input / Select / Form / Table / Modal / Drawer / Tabs / Menu / Card / List / Tag / Message / Empty | 中后台高频，必详细 |
| P1 | DatePicker / Upload / Switch / Checkbox / Radio / Badge / Avatar / Breadcrumb / Pagination / Steps / Tooltip / Notification / Result / Spin / Progress / Statistic | 常用，需详细 |
| P2 | 业务封装组件（搜索区、筛选区、数据卡片等） | 基于基础组件组合，见 [组件封装策略](../工程落地/组件封装策略.md) |
