# Tag 标签

> 标签用于标记状态、分类、属性。轻量、可多、可组合。

---

## 1. 概述

标记对象属性/状态：状态（进行中/已完成）、分类、计数。

---

## 2. 解剖结构

```
┌──────────┐
│ ● 进行中  │ ← 圆角4px + 文字(12px) + 可选状态点/图标
└──────────┘
```

---

## 3. 变体

| 类型 | 说明 |
|---|---|
| 实色标签 | 主色/功能色底，白字（强调） |
| 描边标签 | 浅色底/描边（默认） |
| 状态点标签 | 前置彩色圆点（状态） |
| 可关闭 | 后置 ×（筛选条件常用） |
| 可点击 | 可切换选中 |

---

## 4. 颜色映射（状态语义）

| 状态 | 颜色 | 示意 |
|---|---|---|
| 成功 | `colorSuccess` | 已完成 |
| 处理中 | `colorPrimary` | 进行中 |
| 警告 | `colorWarning` | 待审核 |
| 错误 | `colorError` | 失败 |
| 默认 | 灰色 | 普通 |

---

## 5. 尺寸

- 字号 12px，圆角 4px（borderRadiusXS）
- 内边距 0 8px，高度约 22px

---

## 6. Do / Don't

**Do**
- ✅ 状态用功能色，分类用中性/主色
- ✅ 筛选标签可关闭（×）
- ✅ 一对象标签 ≤ 3 个

**Don't**
- ❌ 用 Tag 做主操作按钮（用 Button）
- ❌ 颜色语义冲突（成功色表"失败"）

---

## 7. 代码

```tsx
<Tag color="success">已完成</Tag>
<Tag color="processing">进行中</Tag>
<Tag closable onClose={...}>筛选条件</Tag>
```
