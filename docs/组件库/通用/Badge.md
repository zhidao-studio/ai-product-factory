# Badge 徽标

> 标记数量或未读状态，附着于图标/列表项右上角。

---

## 1. 解剖
```
        ●(红点)
   [🔔]   或  [🔔] 5(数字角标)  或  [🔔] New(文字)
```

## 2. 变体
- 红点（仅提示有更新）
- 数字（count，>99 显 99+）
- 文字（如"New"）
- 独立展示（不依附图标）

## 3. 状态
默认主色/错误色；可 `dot` 或 `count`；`overflowCount` 上限。

## 4. Do / Don't
- ✅ 重要未读用数字，弱提示用红点
- ✅ 角标位置固定右上角
- ❌ 数字角标显示精确大数（用 99+）

## 5. 代码
```tsx
<Badge count={5}><BellIcon /></Badge>
<Badge dot><MessageIcon /></Badge>
```
