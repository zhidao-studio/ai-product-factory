# Tabs 标签页

> 在同一区域内切换互斥的内容视图，不跳页。

---

## 1. 概述

用于内容分类切换、详情页子模块（基本信息/订单/日志）。切换不打断上下文。

---

## 2. 解剖结构

```
┌──────────────────────────────────┐
│ [标签一] [标签二] [标签三]         │ ← Tab Bar (选中态下划线/填充)
├──────────────────────────────────┤
│ 对应标签的内容区                   │
└──────────────────────────────────┘
```

---

## 3. 状态

| 状态 | 视觉 |
|---|---|
| Default | 灰色文字 |
| Active | 主色文字 + 主色下划线（PC）/ 主色填充胶囊（移动端） |
| Disabled | 灰字不可点 |

---

## 4. 变体

| 类型 | 位置 | 适用 |
|---|---|---|
| 线型 | 顶部 | PC 详情页（默认） |
| 卡片型 | 顶部 | 分组感强 |
| 分段控件 | 顶部 | 选项 ≤ 4，移动端常用 |
| 可滚动 | 顶部 | 标签多时横向滚动 |

---

## 5. 数量约束

- PC：标签 ≤ 8，超出滚动
- 移动端：标签 ≤ 5，超出用「更多」或分段

---

## 6. Do / Don't

**Do**
- ✅ 标签语义互斥、并列
- ✅ 选中态清晰（颜色 + 指示条）
- ✅ 内容切换有淡入（200ms）

**Don't**
- ❌ 用 Tabs 做导航（用 Menu）
- ❌ 标签数量过多不滚动

---

## 7. 代码

```tsx
// PC
<Tabs items={[{key:'1',label:'基本信息',children:...},{key:'2',label:'订单'}]} />

// 移动端 (antd-mobile)
<Tabs>{[{title:'基本信息',key:'1'},{title:'订单',key:'2'}].map(...)}</Tabs>
```

---

## 8. 无障碍

- `role="tablist"` / `tab` / `tabpanel`
- 左右方向键切换标签
- 选中 `aria-selected`
