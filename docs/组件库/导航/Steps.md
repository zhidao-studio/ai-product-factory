# Steps 步骤条

> 展示流程进度，引导多步任务。

---

## 1. 解剖
```
(1)✓  完成  ──  (2)● 进行中  ──  (3)○ 待处理
```
节点 + 连接线 + 标题 + 描述。

## 2. 变体
| 类型 | 适用 |
|---|---|
| 水平 | PC 流程页 |
| 垂直 | 移动端/侧栏 |
| 点状 | 简洁 |
| 导航式 | 可点击跳步 |

## 3. 状态
wait(待处理) / process(进行中,主色) / finish(完成,主色勾) / error(错误,错误色)。

## 4. Do / Don't
- ✅ 步骤 ≤ 5，超出用垂直/滚动
- ✅ 当前步高亮，已完成可回跳
- ❌ 步骤文案含糊（"步骤1"→"填写信息"）

## 5. 代码
```tsx
<Steps current={1} items={[{title:'填写信息'},{title:'确认'},{title:'完成'}]} />
```
