# Breadcrumb 面包屑

> 指示页面在层级中的位置，支持快速上跳。

---

## 1. 解剖
```
首页 / 用户管理 / 用户详情
```
分隔符 `/` 或 `>`；末级为当前页（不可点）。

## 2. 变体
- 水平文字链
- 可折叠（层级深时收起中间）
- 带图标

## 3. Do / Don't
- ✅ 末级不可点（当前页）
- ✅ 与 Menu 选中态一致
- ❌ 移动端用面包屑（空间不足，用返回按钮）

## 4. 代码
```tsx
<Breadcrumb items={[{title:<a>首页</a>},{title:<a>用户管理</a>},{title:'用户详情'}]} />
```
