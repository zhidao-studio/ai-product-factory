# Menu 菜单

> 菜单承载后台系统的全局导航。PC 用侧边/顶部，移动端用 NavBar + 抽屉。

---

## 1. 概述

用于多页面/多级导航。PC 中后台首选侧边 Menu，平板/大屏可混合顶部。

---

## 2. 解剖结构（侧边）

```
┌─────────────┐
│ ◉ Logo       │ ← 品牌区
├─────────────┤
│ 🏠 概览       │ ← 一级菜单(选中态主色背景)
│ 📊 数据       │
│   ├ 报表      │ ← 二级(展开)
│   └ 统计      │
│ ⚙ 设置       │
└─────────────┘
```

---

## 3. 状态

| 状态 | 视觉 |
|---|---|
| Default | 灰字 |
| Hover | 浅灰背景（PC） |
| Selected | 主色文字 + 主色浅背景 `#E6F4FF` |
| Open(子菜单) | 展开指示 |

---

## 4. 变体

| 类型 | 位置 | 适用 |
|---|---|---|
| 侧边内联 | 左侧固定 | 中后台（多级） |
| 顶部水平 | 顶栏 | 一级 ≤ 5 |
| 混合 | 顶部+侧边 | 复杂系统 |
| 折叠 | 侧边 48px 图标 | 宽屏节省空间 |

---

## 5. 数量约束

- 一级菜单 ≤ 7（超出用分组/搜索）
- 层级 ≤ 3
- 移动端用抽屉导航（见 [导航模式](../UX交互/导航模式.md)）

---

## 6. Do / Don't

**Do**
- ✅ 当前页高亮（主色背景）
- ✅ 折叠态保留图标+Tooltip
- ✅ 面包屑辅助定位

**Don't**
- ❌ 菜单项文案含糊（"管理"→"用户管理"）
- ❌ 移动端直接搬 PC 侧边 Menu

---

## 7. 代码

```tsx
// PC 侧边
<Layout.Sider>
  <Menu mode="inline" selectedKeys={[key]} items={menuItems} />
</Layout.Sider>

// 移动端 NavBar
<NavBar back="返回" onBack={goBack}>标题</NavBar>
```

---

## 8. 无障碍

- `role="menu"` / `menuitem`
- 展开项 `aria-expanded`
- 键盘上下导航，Enter 进入
