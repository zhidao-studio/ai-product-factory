# 图表色彩与色板

> 模块：数据可视化 ｜ 适用：所有含图表的端（PC Web / H5 / 小程序 / 大屏）
> 关联：色彩系统、无障碍设计、数据可视化/图表元素规范

图表不是"换个颜色就好看"，而是**数据可信度**的载体。错误的色板会让用户误读趋势、混淆类别。本文定义本设计系统内的图表色板与语义映射，所有图表库（ECharts / AntV / Recharts / 自研）必须从中取色。

---

## 1. 取色总原则

1. **数据色 ≠ 品牌色**：主色 `#1677FF` 只用于"强调/选中/交互"，不独占一类数据；连续类目数据用下方分类色板。
2. **类别数 ≤ 10**：超过 10 个分类必须分组、聚合或改用其他图表，禁止硬塞 12 色。
3. **语义色固定**：成功/警告/危险/信息沿用 `colorSuccess/Warning/Error/Info`，用于状态而非装饰。
4. **对比度 ≥ 3:1**（WCAG AA 对图表元素 / UI 的要求）；相邻类别色差必须可分辨（HSL 色相间隔 ≥ 30° 或亮度差 ≥ 15%）。
5. **明暗双套**：所有色板提供 light / dark 两套，dark 下整体提亮 8%~15% 以适配深色背景。

---

## 2. 分类色板（Categorical，10 色）

用于离散类别对比（柱状、折线多序列、饼图、雷达）。

| 序号 | 名称 | Light | Dark |
|---|---|---|---|
| C1 | 蓝 | `#1677FF` | `#4096FF` |
| C2 | 青 | `#13C2C2` | `#36CFC9` |
| C3 | 绿 | `#52C41A` | `#73D13D` |
| C4 | 黄绿 | `#99CC33` | `#B7E861` |
| C5 | 金 | `#FAAD14` | `#FFC53D` |
| C6 | 橙 | `#FA8C16` | `#FFA940` |
| C7 | 红 | `#FF4D4F` | `#FF7875` |
| C8 | 紫 | `#722ED1` | `#9254DE` |
| C9 | 品红 | `#EB2F96` | `#F759AB` |
| C10 | 灰蓝 | `#5B8FF9` | `#85A5FF` |

- 顺序按"冷暖交替 + 饱和梯度"排列，避免相邻同色系。
- 无障碍友好：C7(红) 与 C3(绿) 不可用于"对错"之外的类别配对，避免色盲混淆（红绿色盲约占男性 8%）。

---

## 3. 连续色板（Sequential）

用于热力图、密度、进度深浅。

- 蓝序：`#E6F4FF → #69B1FF → #1677FF → #0958D9`
- 灰序：`#F5F5F5 → #D9D9D9 → #8C8C8C → #434343`
- 规则：同色相明度递增，端点对比 ≥ 3:1，禁止跨色相跳变。

---

## 4. 发散色板（Diverging）

用于正负、增减、偏离（如盈亏、温差）。

- 蓝-红：`#1677FF → #FFFFFF(或 #F5F5F5) → #FF4D4F`
- 绿-红：`#52C41A → #FAFAFA → #FF4D4F`
- 中值必须接近似白/浅灰，避免中间"脏色"。

---

## 5. 语义映射（状态而非装饰）

| 语义 | 色值 | 用途 |
|---|---|---|
| 成功 / 正向 | `colorSuccess #52C41A` | 达标、增长（非对比场景） |
| 警告 / 临界 | `colorWarning #FAAD14` | 接近阈值 |
| 危险 / 负向 | `colorError #FF4D4F` | 超标、下跌（非对比场景） |
| 信息 / 选中 | `colorInfo #1677FF` | 高亮当前维度 |

> 警告：在"涨跌对比"场景，红绿语义色优先于分类色板——此时红=跌、绿=涨是用户强预期，不要为"美观"改用蓝橙。

---

## 6. 中性与辅助

| 用途 | Light | Dark |
|---|---|---|
| 轴线 / 网格 | `rgba(5,5,5,0.06)` | `rgba(255,255,255,0.12)` |
| 文本标签 | `colorTextSecondary` | `rgba(255,255,255,0.65)` |
| 背景 | `colorBgContainer` | `#1F1F1F` |
| 高亮描边 | `colorPrimary` | `#4096FF` |

---

## 7. 反模式

- ❌ 用主色 `#1677FF` 画满 6 条折线 → 类别不可区分
- ❌ 红绿配色用于"类别"而非"涨跌"
- ❌ 渐变里插入第三个色相导致中间脏色
- ❌ 深色模式直接复用 light 色值（对比度崩）
- ❌ 饼图扇区 > 7 块且无"其他"聚合
- ❌ 色盲不可分辨的相邻色（红/绿、蓝/紫靠太近）

---

## 8. 自检清单

- [ ] 数据色取自分类/连续/发散色板，未用品牌色独占类别
- [ ] 类别 ≤ 10，超出已聚合
- [ ] 相邻类别可分辨（色相/亮度差达标）
- [ ] light / dark 双套已配
- [ ] 语义色仅用于状态，未误用于类别
- [ ] 对比度 ≥ 3:1
