# 图表类型选择

> 模块：数据可视化 ｜ 用途：快速决策"什么数据用什么图"
> 黄金法则：**先想清楚要回答什么问题，再选图**。图表服务于"比较 / 构成 / 分布 / 趋势 / 关联"五类问题。

---

## 0. 选型决策树

```
要表达什么？
├─ 趋势（随时间变化）      → 折线图 / 面积图
├─ 比较（类别间大小）      → 柱状图 / 条形图
├─ 构成（占整体比例）      → 饼图 / 环图 / 堆叠柱
├─ 分布（密度/区间）       → 直方图 / 散点 / 箱线
├─ 关联（两变量关系）      → 散点图 / 气泡图
├─ 流程/转化              → 漏斗图 / 桑基图
├─ 地理                  → 地图（需合规底图）
└─ 多维度雷达             → 雷达图（仅 ≤ 6 维）
```

---

## 1. 趋势类

| 图表 | 适用 | 注意 |
|---|---|---|
| 折线图 | 连续时间点、多序列对比 | 序列 ≤ 5，超出用"选中高亮"其余置灰 |
| 面积图 | 强调总量与趋势 | 单序列用纯色半透明；多序列用堆叠 |
| 堆积面积 | 构成 + 趋势 | 类目 ≤ 5 |

---

## 2. 比较类

| 图表 | 适用 | 注意 |
|---|---|---|
| 柱状图 | 离散类别对比，数量级相近 | 类目 ≤ 12；负值向下 |
| 条形图 | 类目名长 / 类目多（>8） | 按值排序更易读 |
| 分组/堆叠柱 | 子分类对比 | 分组 ≤ 4 组，堆叠 ≤ 5 段 |

---

## 3. 构成类

| 图表 | 适用 | 注意 |
|---|---|---|
| 饼图 | 占比，类目 ≤ 5 | 从 12 点顺时针，最大块起；禁 3D |
| 环图（Donut） | 占比 + 中心放总数 | 中心放 KPI 大数 |
| 百分比堆叠柱 | 多组各自的构成 | 每组 100% 归一 |

> 反例：用饼图比较"随时间变化"——饼图无时间维度，改用堆叠面积。

---

## 4. 分布与关联

| 图表 | 适用 |
|---|---|
| 直方图 | 单变量分布 |
| 散点图 | 两变量相关性，可加趋势线 |
| 气泡图 | 三变量（x/y/大小） |
| 箱线图 | 统计分布（中位数/四分位） |

---

## 5. 流程与多维度

| 图表 | 适用 | 注意 |
|---|---|---|
| 漏斗图 | 转化率逐层 | 相邻层差值标注 |
| 桑基图 | 多对多流向 | 节点 ≤ 20，防交叉混乱 |
| 雷达图 | 多维能力对比 | 维度 ≤ 6，否则不可读 |
| 热力图 | 二维密度/时段活跃 | 用连续色板 |

---

## 6. 移动端特别约束

- 屏幕窄：**优先条形图 / 环图 / 迷你 sparkline**，避免多序列折线。
- 交互：用"点击图例 + 长按 tooltip"替代 hover。
- 尺寸：图表最小触摸热区 ≥ 44px；小图表可内联在卡片（StatCard）。
- 禁：PC 仪表盘直接缩放塞进手机——需重排为单列卡片流。

---

## 7. 反模式

- ❌ 饼图 > 7 块
- ❌ 3D 任何图表
- ❌ 用饼图表达趋势
- ❌ 雷达图 > 6 维
- ❌ 坐标轴静默截断
- ❌ 移动端硬塞 PC 双轴组合图

---

## 8. 速查自检

- [ ] 图表类型匹配"问题类型"（比较/构成/趋势/分布/关联）
- [ ] 类目/维度数在限制内
- [ ] 移动端已重排（非缩放）
- [ ] 无 3D、无静默截断
