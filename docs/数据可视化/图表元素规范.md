# 图表元素规范

> 模块：数据可视化 ｜ 关联：图表色彩与色板、图表类型选择
> 目标：统一坐标轴、网格、图例、tooltip、标签的密度与样式，保证"信息密度高但不杂乱"。

本文面向所有图表组件（折线/柱状/饼/面积/散点/雷达/热力/漏斗/桑基等）。样式 Token 统一从 `design-tokens.json` 取，禁止自造。

---

## 1. Data-Ink 比原则（Tufte）

> 每一寸墨水要么承载数据，要么承载必要结构；装饰性墨水一律删除。

- 删除：3D 柱体、渐变背景、花哨阴影、无用网格。
- 保留：坐标轴、必要的刻度、数据标签、图例。
- 网格线默认隐藏次要、显示主要（主网格 `rgba(5,5,5,0.06)`，次网格不画）。

---

## 2. 坐标轴（Axis）

| 项 | 规范 |
|---|---|
| 轴线 | 浅灰 `colorSplit`，1px；横轴在底，纵轴在左 |
| 刻度数量 | 纵轴 4~6 格；横轴按数据密度，避免重叠 |
| 刻度标签 | `colorTextSecondary`，字 12px（PC）/ 12px（移动端可缩到 10px） |
| 单位 | 轴标题统一放轴末端，如"金额（元）"，不重复在每格 |
| 0 基线 | 数值轴必须从 0 起始（防止误导幅度），除非是"偏离 0 的对比轴"（需标注） |
| 截断 | 轴截断必须画断裂符号 `//` 并注明，禁止静默截断 |

---

## 3. 网格（Grid）

- 主网格线：横轴类图表画横向主网格，纵向不画（减少噪音）。
- 颜色：`rgba(5,5,5,0.06)` light / `rgba(255,255,255,0.12)` dark。
- 移动端：网格可全隐，仅保留坐标轴。

---

## 4. 图例（Legend）

| 项 | 规范 |
|---|---|
| 位置 | PC：图表右上或下方；移动端：图表下方横排，可滚动 |
| 交互 | 点击图例可隐藏/显示对应序列（必须支持） |
| 样式 | 小方块 8×8px 圆角 2，色取对应序列；文字 `colorTextSecondary` 12px |
| 数量 | 图例项 ≤ 10，超出折叠为"更多" |

---

## 5. Tooltip（悬浮提示）

| 项 | 规范 |
|---|---|
| 触发 | hover（PC）/ 长按或点击（移动端） |
| 容器 | `colorBgElevated` + `shadow.default`，圆角 `radius.base`(6)，padding `space.sm`(12) |
| 标记 | 每项前带对应色点 8px |
| 数值 | 主值 `colorText` 14px medium；单位灰 |
| 排序 | 多序列按数值降序，便于快速定位最大项 |
| 空数据 | 显示"暂无数据"，不显示空 tooltip |
| 位置 | 跟随指针，边缘自动翻转避免溢出视口 |

---

## 6. 数据标签（Label）

- 仅在"数值重要且位置不挤"时显示（如 KPI 大数、饼图占比）。
- 柱/条形：标签置于图形外或内部（对比度需 ≥ 3:1）。
- 折线：端点标签可选，避免每点都标。
- 移动端：高密度图表默认隐藏标签，靠 tooltip 查看。

---

## 7. 标题与注释

| 项 | 规范 |
|---|---|
| 图表标题 | `colorText` 14px medium，左上对齐 |
| 副标题/口径 | `colorTextTertiary` 12px，标题下方 |
| 标注线 | 参考线用 `colorWarning` 虚线 + 标签"目标值" |
| 数据源 | 图表右下 12px `colorTextTertiary`，如"数据来源：BI 系统" |

---

## 8. 响应式与空态

- 容器宽度变化：PC 显示完整坐标轴+图例；移动端隐藏网格、图例下移、标签精简。
- 空数据：统一用 `Empty` 组件（见组件库/数据展示/Empty），不画空白坐标轴。
- 加载：首屏用骨架（占位同尺寸矩形，颜色 `colorBgLayout`），不用整页 spinner。

---

## 9. 反模式

- ❌ Y 轴不从 0 起始且未标注（误导幅度）
- ❌ 3D 柱状/饼图（扭曲比例）
- ❌ 主网格 + 次网格全画（噪音）
- ❌ tooltip 无单位、无排序
- ❌ 图例不可点击隐藏
- ❌ 饼图标百分比但总和 ≠ 100%（四舍五入需调和为 100）

---

## 10. 自检清单

- [ ] 数值轴从 0 起（或已标注对比轴）
- [ ] 网格克制（仅主网格）
- [ ] 图例可交互隐藏
- [ ] tooltip 含单位、有排序、边缘翻转
- [ ] 标签密度合理（移动端精简）
- [ ] 空态用 Empty，加载用骨架
- [ ] 标题/口径/数据源齐全
