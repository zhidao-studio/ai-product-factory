# PC Web 平台适配

> PC 中后台主战场。信息密度高，依赖鼠标/键盘交互。

---

## 1. 布局结构

```
┌──────────────────────────────────────────────┐
│ 顶部导航 64px                                  │
├────────┬─────────────────────────────────────┤
│ 侧边栏  │ 内容区（24 列栅格）                   │
│ 200px   │                                     │
├────────┴─────────────────────────────────────┤
│ 底部（可选）48px                               │
└──────────────────────────────────────────────┘
```

## 2. 尺寸规范

| 参数 | 值 |
|---|---|
| 顶部导航高 | 64px（默认）/ 48px（紧凑） |
| 侧边栏宽 | 200px / 折叠 48px |
| 内容边距 | 24px / 16px（紧凑） |
| 卡片内边距 | 24px / 16px |
| 表格行高 | 48 / 40（紧凑）/ 44 |
| 按钮高 | 32 / 40(large) / 24(small) |
| 页面最大宽 | 1920（推荐内容 1200） |

## 3. 内容密度

| 模式 | 说明 | 开启 |
|---|---|---|
| 默认 | 标准间距 | — |
| 紧凑 | 缩小尺寸 | `theme.compactAlgorithm` |

## 4. 交互特性（鼠标/键盘）

- Hover 态（移动端无）
- 右键上下文菜单
- 键盘快捷键
- 拖拽排序
- 多选（Ctrl/Shift+Click）
- Tooltip 悬浮

## 5. 字号（PC）

| 用途 | 字号 | 行高 |
|---|---|---|
| 页面标题 | 24 | 32 |
| 区块标题 | 20 | 28 |
| 子标题 | 16 | 24 |
| 正文 | 14 | 22 |
| 辅助 | 12 | 20 |

## 6. 响应式

- 断点 480/576/768/992/1200/1600/1920
- 侧边栏窄屏折叠；表格横向滚动
- 见 [栅格与布局](../基础规范/栅格与布局.md)

## 7. 与本系统对齐

- 组件见 [组件库](../组件库/)（antd）
- 深色/紧凑主题见 [主题切换实现](../工程落地/主题切换实现.md)

## 8. 规则

- ✅ 信息密度靠紧凑模式，不压字号
- ✅ 表格操作列固定右
- ❌ 移动端布局直接搬 PC（需响应式/独立移动端）
