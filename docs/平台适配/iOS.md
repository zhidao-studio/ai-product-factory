# iOS 平台适配

> iOS 遵循 Apple HIG。在统一 AntD 语言基础上，尊重 iOS 原生交互与 Liquid Glass 设计语言。

---

## 1. 设计原则（HIG）

| 原则 | 含义 |
|---|---|
| Clarity 清晰 | 内容优先，界面退居幕后 |
| Consistency 一致 | 遵循系统标准交互 |
| Deference 顺从 | UI 不与内容争注意力 |
| Depth 层次 | 通过层级/动效传达空间 |

---

## 2. Liquid Glass（iOS 26+）

- **材质**：控件半透明玻璃，悬浮于内容
- **同心圆角**：嵌套形状圆角绕共同中心对齐
  - 固定形：恒定半径
  - 胶囊：半径 = 高度/2
  - 同心：内层 = 外层 − 内边距
- **滚动边缘效果**：替代硬分割线，模糊过渡
- **条形栏简化**：移除多余背景/边框，靠分组与空间表达层级
- **背景扩展**：内容可延伸到边栏后方

> 自定义控件须与系统节奏协调，避免缩太近/展太开的角。

## 3. 布局参数

| 参数 | 值 |
|---|---|
| 最小触控目标 | 44×44 pt |
| 安全区顶 | 状态栏+导航栏 ≈ 88pt |
| 安全区底 | Home Indicator 34pt |
| 页面边距 | 16pt |
| 导航栏高 | 44pt（Large Title 96pt） |
| 标签栏高 | 49pt |
| 工具栏高 | 44pt |

## 4. 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| Large Title | SF Pro Display | 34pt | Bold |
| Title | SF Pro Display | 17pt | Semibold |
| Body | SF Pro Text | 17pt | Regular |
| Caption | SF Pro Text | 12pt | Regular |

---

## 5. 交互特性

- 右滑返回（边缘轻扫）
- Haptic Touch 上下文菜单
- 下拉刷新（系统标准）
- 模态从底部滑入
- **Dynamic Type**：支持动态字号（见 [无障碍设计](../基础规范/无障碍设计.md)）

---

## 6. 与本系统对齐

- 主色用 `#1677FF`，但遵循 iOS 圆角偏好（大圆角 10~16px）
- 动效时长/曲线见 [动效系统](../基础规范/动效系统.md)
- 手势：用系统返回，不自定义边缘手势冲突

---

## 7. 规则

- ✅ 尊重安全区（刘海/Home）
- ✅ 主操作底部 Tab 或导航栏右
- ❌ 全宽按钮不贴边（留安全边距）
- ❌ 隐藏状态栏（除非沉浸式媒体）
