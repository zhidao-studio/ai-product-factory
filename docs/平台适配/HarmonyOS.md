# HarmonyOS 平台适配

> HarmonyOS 遵循官方设计指南，支持多设备协同。宇宙蓝主色 + 24vp 图标规范。

---

## 1. 设计理念

| 理念 | 含义 |
|---|---|
| 全场景 | 多设备协同，一次开发多端部署 |
| 自然连接 | 靠近发现、服务流转 |
| 安全可信 | 隐私优先 |
| 1+8+N | 手机为核心，扩展平板/手表/智慧屏/IoT |

---

## 2. 色彩

| 色彩 | 值 | 用途 |
|---|---|---|
| 宇宙蓝 | `#007DFF` | 系统主色 |
| 雪域灰 | `#F1F3F5` | 卡片背景 |
| 深空黑 | `#000000` | 深色背景 |
| 星辰白 | `#FFFFFF` | 浅色背景 |

> 本系统主色 `#1677FF` 与宇宙蓝接近，可统一；对比度最低 3:1，推荐 4.5:1+。

---

## 3. 图标规范

- 标准 24vp，绘制区 22vp，四周留 1vp
- 描边/填充同结构，几何型、精简线、避尖锐直角
- 关键形状：正方 20 / 圆 22 / 横矩 22×18 / 竖矩 18×22

---

## 4. 布局参数

| 参数 | 值 |
|---|---|
| 最小触控 | 48×48 vp |
| 状态栏 | 28vp+ |
| 标题栏 | 56vp |
| 底部导航 | 80vp |
| 页面边距 | 16vp |

---

## 5. 多设备断点

| 设备 | 断点 | 策略 |
|---|---|---|
| 手机竖 | < 600vp | 单列 |
| 手机横 | 600~840 | 双列 |
| 平板 | 840~1280 | 双/三列 |
| 大屏/折叠 | > 1280 | 多列自适应 |

---

## 6. 特有能力

- 服务卡片（桌面卡片）
- 实况窗（Live Window）
- 靠近发现
- 多设备协同
- 隔空手势
- 应用接入状态栏

---

## 7. 与本系统对齐

- Token 共享（见 [Design Token 架构](../工程落地/Design Token 架构.md)）
- 触控目标 48vp 对齐 [无障碍设计](../基础规范/无障碍设计.md)

---

## 8. 规则

- ✅ 多设备断点适配（一次开发多端）
- ✅ 图标遵 24vp 规范
- ❌ 忽略安全区（折叠/挖孔）
- ❌ 固定死宽不自适应
