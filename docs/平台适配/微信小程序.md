# 微信小程序平台适配

> 微信小程序遵循官方设计指南。轻快、克制，预留系统胶囊菜单空间。

---

## 1. 设计原则

| 原则 | 含义 |
|---|---|
| 友好礼貌 | 重点突出，减少干扰 |
| 清晰明确 | 导航明确，反馈及时 |
| 便捷优雅 | 减少输入，避免误操作 |
| 统一稳定 | 页面一致延续 |

## 2. 设计基准

| 参数 | 值 |
|---|---|
| 设计稿宽 | 375px（固定）/ 390px（响应式） |
| 尺寸单位 | rpx（750rpx = 屏宽） |
| 页面边距 | 32rpx |
| 基准字号 | 28rpx（14px） |

## 3. 字体

| pt | rpx | 用途 |
|---|---|---|
| 22 | 44 | 大标题 |
| 17 | 34 | 导航/卡片标题 |
| 15 | 30 | 重要 |
| 14 | 28 | 正文 |
| 12 | 24 | 辅助 |

## 4. 色板

| 用途 | 值 |
|---|---|
| 主要文字 | `#333333` |
| 次要文字 | `#666666` |
| 辅助文字 | `#999999` |
| 链接 | `#576B95` |
| 微信绿 | `#07C160` |
| 错误 | `#FA5151` |

> 品牌主色可用 `#1677FF`（AntD），与微信绿并存需谨慎（微信绿仅用于微信原生语义）。

## 5. 导航

- **小程序菜单**：右上角胶囊，不可自定义，需预留 88×32px 空间
- **底部 Tab**：2~5 个（首页专用），可自定义图标/文案
- **次级页**：左上返回；iOS 右滑返回；Android 物理返回

## 6. 反馈

| 类型 | 时长 | 场景 |
|---|---|---|
| 图标提示 | 1.5s | 轻量成功 |
| 文字提示 | 1.5s | 轻量状态 |
| 模态框 | 用户关 | 重要结果 |
| 结果页 | 持续 | 流程终结 |
| 原位报错 | 持续 | 表单错误 |

## 7. 加载

- 启动页：微信统一，不可自定义
- 下拉刷新：系统标准
- 局部加载：推荐（触发区反馈）
- 模态加载：谨慎（引焦虑）
- 同页 ≤ 1 加载动画；长加载给进度+取消

## 8. 表单

| 控件 | 高 | 说明 |
|---|---|---|
| 输入框 | 88rpx+ | 触控 |
| 按钮 | 88rpx+ | 主操作 |
| 点击区 | ≥ 44×44px | 物理 7~9mm |

## 9. 组件（antd-mini / WeUI）

| 场景 | 组件 |
|---|---|
| 按钮 | Button |
| 表单 | Form / Input / Picker |
| 列表 | List / SwipeAction |
| 导航 | TabBar / NavBar |
| 反馈 | Toast / Dialog |
| 展示 | Card / Steps / Badge |

## 10. 特有能力（提效）

- `wx.scanCode` 扫码
- `wx.getLocation` 定位
- `wx.requestPayment` 支付
- `onShareAppMessage` 分享
- 云开发 Cloud Base

## 11. 规则

- ✅ 预留右上角胶囊菜单空间
- ✅ 底部 Tab ≤ 4（推荐）最多 5
- ✅ 利用系统能力减少输入
- ❌ 自定义小程序菜单胶囊
- ❌ 同页多加载动画
