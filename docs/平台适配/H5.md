# H5 平台适配

> H5 运行于移动端浏览器，跨平台但能力受限。一套代码覆盖 iOS/Android 浏览器。

---

## 1. 定位与特点

| 特点 | 说明 |
|---|---|
| 跨平台 | iOS/Android 浏览器通用 |
| 即用即走 | URL 访问，无需安装 |
| 受限能力 | 浏览器安全策略限制 |
| 性能敏感 | 移动网络/CPU/GPU 受限 |

## 2. 设计基准

| 参数 | 值 |
|---|---|
| 设计稿宽 | 375px（iPhone 标准） |
| 最大内容宽 | 100vw（大屏限 750px 居中） |
| 页面边距 | 16px |
| 基准字号 | 14px（输入 ≥ 16px） |
| 按钮高 | 44px+ |
| 圆角 | 6~8px |
| 图片格式 | WebP（优于 PNG 30%+） |

## 3. 布局

```css
.app { width:100%; max-width:750px; margin:0 auto; min-height:100vh;
  padding:0 16px; padding-bottom: env(safe-area-inset-bottom); }
```

## 4. 交互规范

- 滚动：`-webkit-overflow-scrolling: touch`
- 点击：移除 300ms 延迟（`touch-action: manipulation`）
- 输入：≥ 16px 防 iOS 缩放
- 图片：`loading="lazy"`
- 动画：`transform`/`opacity`（GPU）
- 弹窗：遮罩 + 居中，禁 body 滚动

## 5. 性能优化

- 首屏 < 1.5s（3G）
- WebP 图片，压缩 30%+
- 分包/按需引入
- 长列表虚拟滚动

## 6. 组件（antd-mobile）

```tsx
import { Button, NavBar, TabBar, Card, List, Form } from 'antd-mobile';
```

## 7. 与原生差异

| 能力 | H5 | 原生 |
|---|---|---|
| 推送 | 不支持 | 支持 |
| 摄像头 | 受限 | 完全 |
| 离线 | Service Worker | 完全 |
| 性能 | WebView 限 | 原生 |
| 支付 | H5 支付 | SDK |

## 8. 规则

- ✅ 安全区适配（env）
- ✅ 性能预算（首屏/包体积）
- ❌ 300ms 点击延迟
- ❌ 移动端用 Table（用 List）
