# 结果页

> 流程终结的明确反馈页（提交成功/支付完成/异常）。
>
> **层级**：通用页面骨架 —— 结果类型、图标语义、主操作唯一全端一致。
> **各端落地**：PC 用 `Result` 居中；移动端·H5·小程序用 `Result`+`NavBar` 返回。危险/失败结果须双通道反馈（见 `基础规范/声音与触感反馈.md`）。端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构

```
┌─────────────────────────────────┐
│                                   │
│          [✓ 大图标]               │
│          支付成功                 │ ← Result
│          已成功支付 ¥99.00        │
│     [查看订单]      [返回首页]     │
│                                   │
└─────────────────────────────────┘
```

## 2. 变体
- success：操作成功，提供下一步
- error：失败，提供重试/联系
- 404 / 403：异常页（见 [Result](../../组件库/反馈/Result.md)）

## 3. 移动端
- 居中，图标放大
- 主操作 `block` 底部或居中
- 避免返回歧义（明确"返回首页"）

## 4. Do / Don't
- ✅ 结果明确（成功/失败一眼可见）
- ✅ 提供 1~2 个下一步入口
- ❌ 结果页再弹 Modal（体验打断）
- ❌ 无返回路径（卡死）
