# 设置页

> 系统与个人账户配置，分组 + 表单。
>
> **层级**：通用页面骨架 —— 分组逻辑、开关/表单控件、保存反馈全端一致。
> **各端落地**：PC 用左侧分组 `Menu`+右侧 `Form`；移动端·H5·小程序用 `List` 分组（每组点击进子页）/ 系统设置风格。组件选型见组件库「跨端映射」，端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构（PC）

```
┌────────────────────────────────────────────┐
│ 设置                                        │
├──────────┬─────────────────────────────────┤
│ 基本设置   │ 基本设置                        │ ← 左侧导航 + 右侧表单
│ 通知设置   │   用户名    [Input      ]       │
│ 安全设置   │   语言      [Select     ]      │
│            │   [保存]                       │
└──────────┴─────────────────────────────────┘
```

## 2. 变体
| 类型 | 结构 |
|---|---|
| 单组设置 | 垂直表单 + 保存 |
| 多组设置 | 左侧 Menu 分组 + 右侧表单（如微信/系统设置） |
| 移动端 | 分组 List，每项进入独立设置页 |

## 3. 组成
- 左侧：分组导航（[Menu](../../组件库/导航/Menu.md) 或 锚点）
- 右侧：分组表单（[Form](../../组件库/数据录入/Form.md)）
- 保存：分组独立保存 或 全局保存

## 4. 移动端
```
┌──────────┐
│ < 设置    │
├──────────┤
│ 基本设置 > │ ← List.Item 进入子页
│ 通知设置 > │
│ 隐私 >     │
└──────────┘
```

## 5. Do / Don't
- ✅ 多组用左侧分组导航
- ✅ 设置项有说明（副标题/Tooltip）
- ✅ 危险操作（注销）置底 + 二次确认
- ❌ 所有设置一屏平铺
- ❌ 移动端用左侧分组（用 List 进入）
