# 列表页

> 中后台最高频页面。展示多条同构数据，支持筛选、排序、操作。
>
> **层级**：通用页面骨架 —— 区块结构、状态、Do·Don't 全端一致。
> **各端落地**：PC 用 `Table`/`Menu`/`Drawer`；移动端·H5·小程序用 `List`/`NavBar`+`TabBar`/全屏 `Drawer`。具体组件选型见组件库「跨端映射」，端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构（PC）

```
┌────────────────────────────────────────────┐
│ 页面标题 + 新建按钮(右上)                     │ ← Page Header
├────────────────────────────────────────────┤
│ [筛选区] 关键词 [下拉] [日期] [查询][重置]    │ ← Filter Bar (Card/Form)
├────────────────────────────────────────────┤
│ 表格(含排序/筛选/选择)                        │ ← Table
│ 分页                                         │
└────────────────────────────────────────────┘
```

## 2. 组成部分

| 区块 | 组件 | 规范 |
|---|---|---|
| 页头 | 标题 + 主操作 | 主操作右上，type=primary |
| 筛选区 | Form(inline) + Button | 折叠高级筛选；查询/重置 |
| 数据区 | [Table](../../组件库/数据展示/Table.md) | 行高 48，操作列固定右 |
| 分页 | [Pagination](../../组件库/导航/Pagination.md) | 每页 20 |

## 3. 移动端结构

```
┌──────────────┐
│ 导航栏 + 搜索  │
├──────────────┤
│ [列表项]       │ ← List
│ [列表项]       │
├──────────────┤
│ 底部 Tab       │
└──────────────┘
```
移动端用 [List](../../组件库/数据展示/List.md) + 触底加载，不用 Table。

## 4. 交互
- 筛选：查询即时/手动（默认手动，避免频繁请求）
- 行操作：编辑（Drawer）/删除（Modal 确认）
- 批量：行选择 + 顶部批量操作条
- 空：筛选无结果显 [Empty](../../组件库/数据展示/Empty.md)

## 5. Do / Don't
- ✅ 筛选区可折叠（字段 > 4）
- ✅ 主操作在页头右上
- ✅ 批量操作显已选数量
- ❌ 表格列 > 12 不处理（展开/抽屉）
- ❌ 移动端用 Table
