# 仪表盘

> 数据概览首页，聚合关键指标与图表。
>
> **层级**：通用页面骨架 —— 指标卡布局、图表选型、空/加载态全端一致。
> **各端落地**：PC 多列 `StatCard`+图表网格；移动端·H5 单列卡片流 + 内联 sparkline（**禁用 PC 双轴组合图硬塞**）。图表规范见 `数据可视化/`，端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构（PC）

```
┌────────────────────────────────────────────┐
│ 仪表盘                                        │ ← Title
├────────────────────────────────────────────┤
│ [Statistic][Statistic][Statistic][Statistic] │ ← 指标卡行 (Row/Col)
├────────────────────────────────────────────┤
│ [趋势图 Card 宽2]      [占比图 Card 宽1]      │ ← 图表行
├────────────────────────────────────────────┤

```

## 2. 组成部分

| 区块 | 组件 | 规范 |
|---|---|---|
| 指标行 | [Statistic](../../组件库/数据展示/Statistic.md) in Card | 4~6 个，Row/Col 等分 |
| 图表区 | Card + 图表库 | 见 [数据可视化](#数据可视化) |
| 列表区 | [List](../../组件库/数据展示/List.md)/Table | 排行/最新 |

## 3. 栅格
- 指标卡：24 列，4 个各 span=6，间距 16
- 图表：2:1 或均分，gutter 16

## 4. 数据可视化
- 图表库：AntV (G2/G2Plot) 或 ECharts
- 配色：功能色 + 扩展色板，禁用手绘渐变
- 类型选择：趋势→折线，占比→饼/环，对比→柱状
- 响应式：容器 `ResizeObserver` 自适应

## 5. 加载
- 首屏 Skeleton 占位各卡片
- 卡片独立加载，错误显重试

## 6. Do / Don't
- ✅ 指标卡 ≤ 6，重要置前
- ✅ 图表有标题与单位
- ✅ 空数据/错误有兜底
- ❌ 图表堆砌无重点
- ❌ 移动端照搬复杂仪表盘（简化为卡片列表）
