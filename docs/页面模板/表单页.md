# 表单页

> 数据录入页面，新建/编辑复用同一模板。
>
> **层级**：通用页面骨架 —— 字段分组、校验时机、提交反馈全端一致。
> **各端落地**：PC 用 `Form`(vertical/inline)+`Modal`/`Drawer`；移动端·H5·小程序用 `Form`+全屏 `Drawer`/`NavBar` 保存。输入框字号全端 ≥16px（防 iOS 缩放）。组件选型见组件库「跨端映射」，端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构（PC 垂直表单）

```
┌──────────────────────────────────────┐
│ < 返回  新建用户                        │ ← Header
├──────────────────────────────────────┤
│ 基础信息                                │ ← Section Title
│   姓名 *    [Input          ]          │
│   手机 *    [Input          ]          │
│   角色      [Select         ]          │
├──────────────────────────────────────┤
│ 权限设置                                │
│   启用      (●)                        │ ← Switch
│   范围      ◉ 全部 ○ 部分              │
├──────────────────────────────────────┤
│              [取消]    [提交]           │ ← Footer sticky
└──────────────────────────────────────┘
```

## 2. 长表单策略
- 字段 > 8：用 [Steps](../../组件库/导航/Steps.md) 分步
- 分组：Section Title 分隔
- 校验：失焦 + 提交（见 [Form](../../组件库/数据录入/Form.md)）

## 3. 移动端
- 垂直布局，单列
- 底部固定提交按钮（`block`）
- 调用系统能力（扫码/定位）

## 4. 提交反馈
- 提交中按钮 loading
- 成功 `message.success` + 返回列表
- 失败行内错误 + 滚动定位

## 5. Do / Don't
- ✅ 必填 `*` 标记
- ✅ 底部 sticky 操作区
- ✅ 长表单分步 + 进度保存
- ❌ 一屏超长不分组
- ❌ 移动端水平表单
