# 详情页

> 展示单条记录的完整信息，支持编辑与关联操作。
>
> **层级**：通用页面骨架 —— 区块结构、状态、Do·Don't 全端一致。
> **各端落地**：PC 用 `Descriptions`+右侧 `Drawer`/同页；移动端·H5·小程序用 `NavBar`+全屏 `Drawer`(bottom)/新页。组件选型见组件库「跨端映射」，端专有规则见 `平台适配/<对应端>.md`。

---

## 1. 页面结构（PC）

```
┌────────────────────────────────────────────┐
│ < 返回  标题 + 状态Tag      [编辑][更多▼]    │ ← Header (返回+标题+操作)
├────────────────────────────────────────────┤
│ Tabs: 基本信息 | 关联订单 | 操作日志          │ ← Tabs
├────────────────────────────────────────────┤
│ 信息分组(Descriptions)                       │
│   字段名        字段值                        │
│   字段名        字段值                        │
└────────────────────────────────────────────┘
```

## 2. 组成部分

| 区块 | 组件 | 规范 |
|---|---|---|
| 页头 | 返回 + 标题 + 状态 + 操作 | 操作右上，主操作 primary |
| Tab | [Tabs](../../组件库/导航/Tabs.md) | 分模块，≤ 5 |
| 内容 | Descriptions / Card | 字段分组，标签-值对齐 |
| 编辑 | [Drawer](../../组件库/反馈/Drawer.md) | 右侧滑入表单 |

## 3. 移动端结构
```
┌──────────┐
│ < 标题     │ ← NavBar
├──────────┤
│ 状态Tag    │
│ 卡片:字段   │ ← Card + 列表
│ 卡片:关联   │
├──────────┤
│ [编辑]底部  │ ← 底部固定操作条
└──────────┘
```

## 4. 字段展示
- 用 `Descriptions` 标签-值，标签 14px 二级色，值 14px 主文本
- 长文本截断 + 展开
- 分组用 Card 标题

## 5. Do / Don't
- ✅ 操作在页头右上，编辑用 Drawer 不跳页
- ✅ 字段分组（基础/高级）
- ✅ 移动端底部固定操作条
- ❌ 所有字段平铺不分组
- ❌ 编辑跳新页（用 Drawer 保上下文）
