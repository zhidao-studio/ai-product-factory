# 无障碍设计

> 无障碍不是可选项，是中型及以上项目的合规底线。本系统以 WCAG 2.1 AA 为最低标准。

---

## 1. 对比度（WCAG 2.1）

| 级别 | 正文 | 大文本(18px+/14px+bold) | UI 组件 |
|---|---|---|---|
| AA（最低） | ≥ 4.5:1 | ≥ 3:1 | ≥ 3:1 |
| AAA（推荐） | ≥ 7:1 | ≥ 4.5:1 | ≥ 4.5:1 |

> 见 [色彩系统](色彩系统.md) 文本色梯度，默认即满足 AA。

---

## 2. 触控目标

| 平台 | 最小触控区 |
|---|---|
| iOS | 44×44 pt |
| Android (M3) | 48×48 dp |
| HarmonyOS | 48×48 vp |
| 微信小程序 | 44×44px（物理 7~9mm） |
| PC Web | 32×32px（鼠标） |

> 移动端按钮高度 ≥ 44px；图标按钮加 8px 内边距补足热区。

---

## 3. 焦点管理

- 所有可交互元素有可见焦点轮廓（`controlOutline`）
- Tab 顺序 = 视觉阅读顺序（左→右，上→下）
- Modal 打开焦点移入，关闭焦点返回触发元素
- 键盘：Enter/Space 触发，Esc 关闭弹窗

---

## 4. 语义化

- 语义标签：`<nav> <main> <aside> <section> <header> <footer>`
- 图片 `alt`；表单 `<label for>` 关联
- ARIA：`role` / `aria-label` / `aria-expanded` / `aria-live`（动态内容）
- 动态提示用 `aria-live="polite"` 让读屏播报

---

## 5. 动态字号

- 支持系统字体放大（iOS Dynamic Type / Android Font Scaling）
- 布局用 `rem` / `dp` / `vp` 而非固定 px，放大不破版
- 极端字号下文字可截断 + Tooltip，不挤压布局

---

## 6. 动效偏好

```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

---

## 7. 色盲友好

- 不止靠颜色传信息：状态配图标/文字
- 图表配图案填充或标签，不只靠色相区分
- 错误用 `#FF4D4F` + ⚠ 图标 + 文案，三重表达

---

## 8. 验收清单（详见 [无障碍验收表](../设计协作/无障碍验收表.md)）

- [ ] 全站文本对比度 ≥ AA
- [ ] 所有交互元素可键盘到达并可见焦点
- [ ] 图片有 alt，图标按钮有 aria-label
- [ ] 颜色非唯一信息载体
- [ ] 支持系统字号放大不破版
- [ ] 支持 `prefers-reduced-motion`
