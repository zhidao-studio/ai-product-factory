# 栅格与布局

> 布局决定信息密度与跨屏适配能力。PC 用 24 列栅格，移动端用 4 列 + Flex，统一安全区与断点。

---

## 1. PC Web 栅格（24 列）

| 参数 | 值 |
|---|---|
| 列数 | 24 |
| Gutter（列间距） | 8 / 16 / 24px |
| Offset | 0~24 |
| 内容最大宽度 | 1200px（推荐） / 1920px（上限） |

```tsx
<Row gutter={[16, 16]}>
  <Col span={12}>...</Col>  {/* 半宽 */}
  <Col span={8}>...</Col>   {/* 1/3 */}
  <Col span={4}>...</Col>   {/* 1/6 */}
</Row>
```

---

## 2. 响应式断点

| 断点 | 宽度 | 典型设备 | 布局 |
|---|---|---|---|
| `screenXS` | < 576 | 手机竖屏 | 1~2 列 |
| `screenSM` | ≥ 576 | 手机横屏 | 2~3 列 |
| `screenMD` | ≥ 768 | 平板竖屏 | 3~4 列 |
| `screenLG` | ≥ 992 | 平板横屏 | 4~6 列 |
| `screenXL` | ≥ 1200 | 桌面 | 6~8 列 |
| `screenXXL` | ≥ 1600 | 大屏 | 8~12 列 |
| `screenXXXL` | ≥ 1920 | 超大屏 | 12 列 |

---

## 3. 移动端布局

| 参数 | 值 |
|---|---|
| 基准宽度 | 375px（iPhone 标准设计稿） |
| 栅格列数 | 4 列 |
| 列间距 | 16px |
| 页面边距 | 16px |
| 内容最大宽度 | 600px（大屏居中） |

---

## 4. Flex 布局

```css
.container { display: flex; align-items: center; justify-content: center; gap: 8px; }
```

> 优先 `gap` 控制间距，配合 [间距与圆角](间距与圆角.md) 梯度。

---

## 5. 安全区域

```css
/* iOS 底部 Home Indicator */
padding-bottom: env(safe-area-inset-bottom);
/* 横屏刘海 */
padding-top: env(safe-area-inset-top);
padding-left: env(safe-area-inset-left);
padding-right: env(safe-area-inset-right);
```

## 6. 典型布局结构

### PC Web 中后台
```
┌──────────────────────────────────────┐
│ 顶部导航 64px                          │
├────────┬─────────────────────────────┤
│ 侧边栏  │  内容区（栅格）              │
│ 200px   │                             │
├────────┴─────────────────────────────┤
│ 底部（可选）48px                       │
└──────────────────────────────────────┘
```

### 移动端
```
┌──────────────┐
│ 状态栏(系统)  │
├──────────────┤
│ 导航栏 44~56  │
├──────────────┤
│ 内容区        │
├──────────────┤
│ 底部 Tab 49~80│
├──────────────┤
│ 安全区        │
└──────────────┘
```

---

## 7. 使用规则

- ✅ 移动端单列优先，双列仅用于列表/卡片
- ✅ PC 内容宽度随断点缩放，不固定死宽
- ✅ 安全区适配必须做（尤其 iPhone 刘海/Home）
- ❌ 禁止固定像素宽度导致小屏横向滚动
