# 图标系统

> 图标是界面最密集的视觉元素。统一风格、统一网格、统一状态映射，是中大型项目可维护的前提。

---

## 1. 图标尺寸梯度

| 尺寸 | 用途 |
|---|---|
| 16px | 表格内操作 / 标签内 |
| 20px | 列表项 / 导航项 |
| **24px** | **默认（按钮 / 工具栏）** |
| 32px | 大按钮 / 卡片图标 |
| 48px | 空状态 / 引导页 |
| 64px+ | 大图标展示 |

---

## 2. 风格规范

- **线框（outlined）**：默认风格，线宽 1px（24px 图标）
- **填充（filled）**：选中态 / 强调态
- 两种风格使用**同一图形结构**，降低重新识别成本
- 圆角端点（Caps），避免尖锐直角（HarmonyOS 同原则）

---

## 3. 网格与关键形状

- 图标整体 24×24，绘制区 22×22，四周留 1px 缓冲
- 关键形状：正方形 20、圆形 22、横矩形 22×18、竖矩形 18×22
- 视觉重心居中，允许局部超绘制区但整体不破 24×24

---

## 4. 颜色状态映射（Token）

| 状态 | 色值 | Token |
|---|---|---|
| 默认 | `rgba(0,0,0,0.45)` | `colorIcon` |
| 悬浮 | `rgba(0,0,0,0.88)` | `colorIconHover` |
| 选中/激活 | `#1677FF` | `colorPrimary` |
| 禁用 | `rgba(0,0,0,0.25)` | `colorTextDisabled` |

---

## 5. 图标库选型

| 场景 | 库 |
|---|---|
| antd 组件 | `@ant-design/icons` |
| 移动端 | `antd-mobile-icons` |
| 自定义图标 | SVG，支持 `currentColor` 继承主题色 |
| iOS 原生 | SF Symbols |
| HarmonyOS | HarmonyOS Symbol |

---

## 6. 自定义图标生产流程

1. 在 24×24 网格内绘制，对齐关键形状
2. 导出 SVG，描边转填充（保证缩放清晰）
3. 命名遵循 [命名规范](../设计协作/命名规范.md)（如 `icon-action-edit`）
4. 注册为组件，颜色用 `currentColor`，禁止内联固定色
5. 同时交付 outlined / filled 两版

---

## 7. 使用规则

- ❌ 禁止混合线性与填充风格图标在同一组
- ❌ 禁止图标尺寸非梯度（如 18px / 22px）
- ✅ 图标 + 文字时，间距 8px（见 [间距与圆角](间距与圆角.md)）
- ✅ 功能性图标必须有文字标签或 Tooltip（无障碍）
