# 色彩系统

> 色彩是品牌识别的最强载体。本系统采用 Ant Design 5.x 色彩体系，所有颜色通过 Design Token 定义，禁止在设计中手填色值。

---

## 1. 色彩分层架构

```
Primitive（原始色板）  →  Semantic（语义色）  →  Component（组件色）
   基础 120 色              功能/中性语义          组件级消费 Token
   仅作取色来源              业务直接引用           antd 自动派生
```

- **Primitive**：12 主色 × 10 级 + 中性灰 10 级，作为取色来源，不直接用于界面
- **Semantic**：品牌主色、功能色、文本色、背景色等语义化颜色，业务直接引用
- **Component**：antd 内部由 Semantic 派生，开发无需手动指定

## 2. 品牌主色

| 色阶 | 色值 | 用途 |
|---|---|---|
| blue-1 | `#E6F4FF` | 最浅背景（选中行/Tag 背景） |
| blue-2 | `#BAE0FF` | 浅背景悬浮态 |
| blue-3 | `#91CAFF` | 描边色 / 标签背景 |
| blue-4 | `#69B1FF` | 描边悬浮态 |
| blue-5 | `#4096FF` | 主色悬浮态 |
| **blue-6** | **`#1677FF`** | **品牌主色（默认）** |
| blue-7 | `#0958D9` | 主色激活态 |
| blue-8 | `#003EB3` | 深色文本 |
| blue-9 | `#002C8C` | 极深背景 |
| blue-10 | `#001D66` | 最深色 |

**规则**：
- 主色用于关键操作点、重要状态高亮、品牌图形
- 全站主色占比 ≤ 15%（视觉克制）
- 深色模式下主色微调为 `#1668DC`（提亮以保证对比度）

## 3. 功能色

| 功能 | 浅色 | 深色 | Token | 语义 |
|---|---|---|---|---|
| 成功 | `#52C41A` | `#49AA19` | `colorSuccess` | 操作成功 / 完成 |
| 警告 | `#FAAD14` | `#D89614` | `colorWarning` | 警告 / 风险 |
| 错误 | `#FF4D4F` | `#FF4D4F` | `colorError` | 操作失败 / 错误 |
| 信息 | `#1677FF` | `#1668DC` | `colorInfo` | 一般提示 |

**规则**：
- 功能色语义全局唯一，不要重构（成功色不表示"已读"）
- 每个功能色同主色派生 10 级，`-bg` 用于背景，`-border` 用于描边，`-hover` 用于悬浮

| 语义 | 浅色 | 深色 | Token |
|---|---|---|---|
| 标题文本 | `rgba(0,0,0,0.88)` | `rgba(255,255,255,0.85)` | `colorTextHeading` |
| 正文文本 | `rgba(0,0,0,0.88)` | `rgba(255,255,255,0.85)` | `colorText` |
| 二级文本 | `rgba(0,0,0,0.65)` | `rgba(255,255,255,0.65)` | `colorTextSecondary` |
| 三级文本 | `rgba(0,0,0,0.45)` | `rgba(255,255,255,0.45)` | `colorTextTertiary` |
| 禁用文本 | `rgba(0,0,0,0.25)` | `rgba(255,255,255,0.30)` | `colorTextDisabled` |
| 占位符 | `rgba(0,0,0,0.25)` | `rgba(255,255,255,0.30)` | `colorTextPlaceholder` |
| 默认边框 | `#D9D9D9` | `#424242` | `colorBorder` |
| 分割线 | `rgba(5,5,5,0.06)` | `rgba(255,255,255,0.12)` | `colorSplit` |
| 页面背景 | `#F5F5F5` | `#000000` | `colorBgLayout` |
| 容器背景 | `#FFFFFF` | `#1F1F1F` | `colorBgContainer` |
| 浮层背景 | `#FFFFFF` | `#262626` | `colorBgElevated` |

> 中性色基于 Alpha，浅色/深色模式自动适配，禁止用纯黑纯白直接当文本色。

## 6. 扩展色板（数据可视化 / 标签）

12 组色系（Dust Red / Volcano / Sunset Orange / Calendula Gold / Sunrise Yellow / Lime / Polar Green / Cyan / Daybreak Blue / Geek Blue / Golden Purple / French Magenta），每组派生 10 级。用于图表、分类标签、状态徽标，详见 [AntV 调色板](https://antv.antgroup.com/specification/language/palette)。

---

## 7. 深色模式

通过 `theme.darkAlgorithm` 自动派生，无需重新配色。设计注意：

- 背景反转：`#F5F5F5` → `#000000`，容器 `#FFFFFF` → `#1F1F1F`
- 文本反转为浅色（基于 `rgba(255,255,255,x)`）
- 阴影加深、扩散减小；边框改浅色半透明
- 功能色提亮保持对比度

---

## 8. 使用规则（强制）

1. ❌ 禁止在 Figma / 代码里写死非 Token 色值
2. ✅ 文本对比度 ≥ 4.5:1（WCAG AA），大文本 ≥ 3:1
3. ✅ 不止靠颜色传信息（配图标/文字，色盲友好）
4. ✅ 品牌色占比 ≤ 15%
5. ✅ 主色改色只改 Seed Token `colorPrimary`，全链路自动派生
