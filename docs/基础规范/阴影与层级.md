# 阴影与层级

> 阴影表达 z 轴高度。本系统用三层阴影梯度，配合背景色表达层级，避免滥用重阴影。

---

## 1. 阴影梯度（Token）

| Token | 值 | 层级 | 用途 |
|---|---|---|---|
| `boxShadowTertiary` | `0 1px 2px 0 rgba(0,0,0,0.05)` | Z1 | 卡片基础阴影 |
| `boxShadowSecondary` | `0 6px 16px 0 rgba(0,0,0,0.08), 0 3px 6px -4px rgba(0,0,0,0.12), 0 9px 28px 8px rgba(0,0,0,0.05)` | Z2 | 悬浮卡片 |
| **`boxShadow`** | 同上 | Z3 | 默认阴影（弹窗/下拉） |
| 蒙层 | `rgba(0,0,0,0.45)` | — | Modal 遮罩 |

> 深色模式下阴影加深、扩散减小，或改用更亮的背景色表达层级。

---

## 2. 层级与 Z-Index

| 层级 | Z-Index | 用途 |
|---|---|---|
| 基础内容 | 0 | 页面主体 |
| 固定元素 | 10 | 吸顶 / 吸底栏 |
| 浮层 | 1000 | Dropdown / Popover / Tooltip |
| 模态框 | 1000 | Modal / Drawer |
| 通知 | 2000+ | Notification / Message |

---

## 3. 层级表达三要素

1. **阴影**：浮层类组件（下拉、弹窗）用阴影
2. **背景色差**：卡片 `container` 白 vs 页面 `layout` 灰，无需阴影也能分层
3. **描边**：分割线 / 边框区分相邻元素（移动端更常用，避免重阴影）

> 移动端优先用「背景色差 + 1px 分割线」表达层级，少用阴影（性能 + 视觉克制）。

---

## 4. Material Elevation 参考（Android）

| 层级 | 高度 | 用途 |
|---|---|---|
| 0 | 0dp | 背景 |
| 1 | 1dp | 卡片 / 文本字段 |
| 2 | 3dp | FAB / 菜单 |
| 3 | 6dp | 对话框 |
| 4 | 8dp | 导航栏 |
| 5 | 12dp | 模态底部表单 |

---

## 5. 使用规则

- ❌ 禁止自定义非梯度阴影
- ✅ 同页面阴影层级 ≤ 3 级
- ✅ 弹窗必须有遮罩 + 阴影，明确层级关系
- ✅ 移动端表单/列表用分割线而非阴影
