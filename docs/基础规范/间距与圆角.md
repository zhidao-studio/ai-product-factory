# 间距与圆角

> 间距与圆角是「秩序感」的来源。全部基于 8px 基数与固定圆角梯度，禁止任意值。

---

## 1. 间距系统

### 基础公式
```
y = 8 + 8 × n   (n ≥ 0)
```

### 间距梯度（Token）

| Token | 值 | 用途 |
|---|---|---|
| `marginXXS` / `paddingXXS` | 4px | 图标与文字间距 |
| `marginXS` / `paddingXS` | 8px | 小间距（表单元素间） |
| `marginSM` / `paddingSM` | 12px | 中小间距（列表项间） |
| `margin` / `padding` | 16px | **默认间距（卡片内边距）** |
| `marginMD` / `paddingMD` | 20px | 中间距（区块间） |
| `marginLG` / `paddingLG` | 24px | 大间距（分区之间） |
| `marginXL` / `paddingXL` | 32px | 超大间距（页面级分区） |
| `marginXXL` | 48px | 最大间距（页面顶/底留白） |

### 垂直间距层级（亲密性量化）

| 层级 | 间距 | 表达的信息关系 |
|---|---|---|
| 小间距 | 8px | 同一组内元素 |
| 中间距 | 16px | 同区块内不同组 |
| 大间距 | 24px | 不同区块 |

### 页面安全边距

| 平台 | 左右边距 | 底部安全区 |
|---|---|---|
| iOS | 16px | 34px (Home Indicator) |
| Android | 16px | 48dp |
| HarmonyOS | 16vp | 48vp |
| PC Web | 24~48px | — |
| H5 | 16px | 34px |
| 微信小程序 | 16~32rpx | 系统处理 |

## 2. 圆角系统

### 圆角梯度（Token）

| Token | 值 | 用途 |
|---|---|---|
| `borderRadiusXS` | 2px | 标签 / 徽章 |
| `borderRadiusSM` | 4px | 小按钮 / 输入框（紧凑） |
| **`borderRadius`** | **6px** | **默认（按钮/输入框/卡片）** |
| `borderRadiusLG` | 8px | 大卡片 / 模态框 |
| `borderRadiusOuter` | 4px | 外部圆角（嵌套计算） |
| 胶囊 | height/2 | 胶囊按钮 / 标签 |
| 圆形 | 50% | 头像 / 图标按钮 |

### 嵌套圆角规则

```
内层圆角 = 外层圆角 − 内边距
例：卡片圆角 8px，内边距 16px → 内部元素圆角取 0（直角）或 borderRadiusSM(4px)
```

### 各平台圆角偏好

| 平台 | 偏好 | 说明 |
|---|---|---|
| iOS | 大圆角 10~16px | Liquid Glass 同心圆角 |
| Android M3 | 8~16dp 按类型 | Shape System |
| HarmonyOS | 8~12vp | 接近 AntD 默认 |
| PC Web | 小圆角 4~8px | 信息密度高 |
| H5 | 6~8px | 同 antd-mobile |
| 微信小程序 | 4~8rpx | 同 WeUI |

---

## 3. 使用规则

- ❌ 禁止出现 3px / 5px / 7px 等非梯度间距与圆角
- ✅ 卡片内边距默认 16~24px，移动端 16px
- ✅ 嵌套圆角按公式递减，避免「圆角套圆角」视觉冲突
- ✅ Flex 布局优先用 `gap` 而非 margin 控制元素间距
