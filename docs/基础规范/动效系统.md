# 动效系统

> 动效不是装饰，而是状态变化的连贯表达。本系统提供统一时长与缓动曲线库，禁止任意动画参数。

---

## 1. 动效原则

1. **自然**：模拟物理运动，用缓动而非线性
2. **克制**：服务于功能，单页同时进行的显眼动画 ≤ 2 个
3. **高效**：时长不超用户预期
4. **连续**：状态变化有过渡，避免生硬

---

## 2. 时长规范

| 场景 | 时长 | Token 参考 |
|---|---|---|
| 微交互（hover / press） | 100ms | `motionUnit` |
| 小范围展开/收起 | 200ms | — |
| 页面切换 / 路由转场 | 300ms | — |
| 模态框 / 抽屉打开 | 300ms | — |
| 大范围形变 | 350~450ms | — |
| 加载动画 | 持续循环 | `opacityLoading` |

---

## 3. 缓动曲线库（Token）

| Token | 曲线 | 用途 |
|---|---|---|
| `motionEaseInOut` | `cubic-bezier(0.645, 0.045, 0.355, 1)` | 通用进出 |
| `motionEaseOut` | `cubic-bezier(0.215, 0.61, 0.355, 1)` | 元素出现 |
| `motionEaseIn` | `cubic-bezier(0.755, 0.05, 0.855, 0.06)` | 元素消失 |
| `motionEaseOutBack` | `cubic-bezier(0.12, 0.4, 0.29, 1.46)` | 弹性出现（带回弹） |
| `motionEaseInBack` | `cubic-bezier(0.71, -0.46, 0.88, 0.6)` | 弹性消失 |
| `motionEaseOutQuint` | `cubic-bezier(0.23, 1, 0.32, 1)` | 优雅减速出现 |
| `motionEaseInOutCirc` | `cubic-bezier(0.78, 0.14, 0.15, 0.86)` | 圆弧进出 |

> **禁止 `linear`**（加载旋转除外）。

---

## 4. 组件动效模式

| 组件 | 进入 | 退出 |
|---|---|---|
| Modal | 淡入 + 缩放 0.8→1 (300ms easeOut) | 淡出 + 缩放 (200ms) |
| Drawer | 从侧滑入 (300ms) | 滑出 (300ms) |
| Dropdown | 淡入 + 上移 8px (100ms) | 淡出 (100ms) |
| Toast | 淡入 + 上移 (200ms) | 淡出 (200ms) |
| 列表项 | 淡入 (200ms) | — |
| 卡片悬浮 | 阴影增强 (100ms) | 恢复 (100ms) |

## 5. 页面转场（移动端）

| 转场 | iOS | Android | HarmonyOS |
|---|---|---|---|
| 推入 | 右滑入 300ms | 淡入上推 300ms | 右滑入 300ms |
| 返回 | 左滑出 300ms | 淡出下滑 300ms | 左滑出 300ms |
| Modal | 底部滑入 350ms | 淡入缩放 300ms | 底部滑入 350ms |
| Tab 切换 | 淡入淡出 200ms | 淡入淡出 200ms | 淡入淡出 200ms |

---

## 6. 性能约束

- 优先 `transform` / `opacity`（GPU 加速），避免 `top/left/width` 动画
- 长列表 / 大数据表格禁用项级进入动画
- 提供 `motion: false` 总开关（见 [主题切换实现](../工程落地/主题切换实现.md)）
- 尊重 `prefers-reduced-motion`

```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

---

## 7. 使用规则

- ❌ 禁止自定义非库缓动曲线
- ❌ 禁止时长 > 500ms 的非必要动画
- ✅ 同一含义动效全局一致（如所有 Modal 同一转场）
- ✅ 骨架屏必须有微动效，否则像卡死
